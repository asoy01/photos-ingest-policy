Photos Picker

Photos Picker is a personal tool used only by its developer, Yoichi Aso (asoy01@gmail.com). It is not offered to other users.

What the tool does

The tool uses the Google Photos Picker API. The user selects photos in the Google Photos picker screen. The tool then downloads only the selected photos to the user's own computer.

Privacy policy

  • The tool requests only one scope: photospicker.mediaitems.readonly. It can read only the photos that the user selects in the picker.
  • Downloaded photos are stored only on the user's own computer.
  • The tool does not send photos or any other user data to third parties.
  • OAuth tokens are stored only on the user's own computer.
  • The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
